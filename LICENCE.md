## 🧩 About

**SCUM catalog Menu** is a curated list of SCUM open-source tools:

- **Overlays** — on-screen helpers, layout notes, loot markers, map overlay
- **Quality-of-Life Helpers** — item catalog, stash manager, overlay notes
- **Research Notes** — survival layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### 🎮 Survival Helpers
- Loot Tracker — highlight nearby loot containers
- Map Overlay — show points of interest and extraction zones
- Item Catalog — browse items, recipes, and stats
- Quick Actions — hotkey helpers for inventory management

### 🎨 Catalog & Cosmetics
- Skin Catalog — browse character appearances and outfits
- Custom Loadout Notes — organize gear presets
- HUD Tweaks — adjust overlay transparency and scale

### 🏋️ Practice Layout
- Single-Player Notes — segment study on any map layout
- Base Building Helper — visualize building boundaries
- Crafting Calculator — plan resource requirements

## ⚙️ Configuration

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `menu_hotkey` | String | `"Tab"` | Toggle overlay |
